# multilingual-stemmer Rust core

A local adaptation of [rust-stemmers](https://github.com/CurrySoftware/rust-stemmers) with WebAssembly bindings. It contains 36 Snowball 3.2.0 algorithms: 35 languages and Early Modern English.

`src/lib.rs` exports `Languages` and `Stemmer` through `wasm-bindgen`. Modules in `src/snowball/algorithms/` are generated by the official Snowball compiler; `src/snowball/` contains its Rust runtime.

```rust
use rust_stemmers::{Languages, Stemmer};

let stemmer = Stemmer::new(Languages::Ukrainian);
assert_eq!(stemmer.stem("акварельний"), "акварел");
```

Algorithms expect lowercase words. Numeric `Languages` values are not part of the API contract.
